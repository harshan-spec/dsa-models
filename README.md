# dsa-models

A searchable, terminal-style reference for the IT22311 Data Structures and Algorithm Laboratory records.

The static site is built with plain HTML, CSS, and JavaScript. It contains 9 exercises and 12 copyable C programs transcribed from the accompanying PDF records. Search ranks matching questions and concepts first, then keeps related programs close behind.

Open `index.html` locally, or serve the folder with any static file server.
